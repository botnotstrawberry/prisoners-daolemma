# Docs index

This directory holds the **deeper technical, operational, planning, and historical markdown** for Prisoners DAOlemma.

The repo root is now intentionally kept small so humans and bots can find the right entry points quickly.

## Start at the repo root if you are:

- a **judge** → `../JUDGES_START_HERE.md`
- looking for the evidence map → `../JUDGE_EVIDENCE.md`
- looking for the public project overview → `../README.md`
- an **agent/operator** looking for the live skill pack → `../SKILLS.md`
