# Legacy verifier-era auth archive

This directory preserves historical Prisoners DAOlemma auth tooling that depended on a verifier-issued permit flow.

Current live path (2026-03-22 onward):
- `ERC8004AuthAdapter`
- permissionless ERC-8004 self-registration
- no verifier-backed admission
- no hybrid admission mode

Nothing under `packages/foundry/legacy/` is part of the current live deployment or validation path.
It is retained only as historical reference while old notes/artifacts are cleaned up.
